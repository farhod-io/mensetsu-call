# mensetsu-call

株式会社CAL (CAL Co., Ltd.) va Yaponiya IT SES/Dasturchi HR suhbatlariga tayyorlanish uchun maxsus interaktiv platforma.

## 🚀 Imkoniyatlar
- **🎮 Interaktiv Suhbat Trenajyori:** 60 soniyalik vizual taymer va yaponcha audio savollar.
- **📊 130+ Atamalar Jadvali:** JLPT N1, N2, N3, SES hamda Kaiwa.live muloqot so'zlari (audio talaffuzi bilan).
- **🗣️ 78+ Kaiwa Muloqot So'zlari:** Interaktiv kartochkalar va suhbatdagi amaliy misol gaplari.
- **📝 10 Oltin Keigo Qolipi:** Kenjougo, Sonkeigo va PREP strukturasidagi javoblar.
- **🗣️ 8 Tayyor Nutq Namunasi:** Nomzod uchun so'zma-so'z aytishga tayyor skriptlar.
- **🏢 CAL Korporativ Dosyesi:** Xodimlar soni (3,280 nafar), 18 ta filial va rasmiy faktlar.
- **💻 IT Texnik Savol-Javoblar:** N+1 muammosi, REST vs GraphQL, React, Xavfsizlik va Git.
- **📹 Web-Suhbat Odobi:** Onlayn suhbat oldidan 8 ta muhim checklist.
- **📋 HR Baholash Varakasi:** Rekruter baholash mezonlari (25%, 25%, 20%, 15%, 15%).
- **📱 PWA (Progressive Web App):** 100% oflayn ishlash, mobil (iOS/Android) hamda kompyuterga ilova sifatida o'rnatish imkoniyati.
